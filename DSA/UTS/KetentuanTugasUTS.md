# **TUGAS UTS – DATA STRUCTURE & ALGORITHM (DSA)**

**Bentuk:** Praktik Coding + Analisis

**Materi:** Array, Stack, Queue, Linked List, Hash Table

---

## **Instruksi Umum**

* Gunakan bahasa pemrograman python untuk mengerjakan
* Semua tugas harus **berjalan (runnable)**
* Pengumpulan:

  * Laporan praktikum disertai dengan penjelasan dan screenshoot output
  * Penjelasan singkat tiap tugas
  * Laporan dikumpulkan dalam format PDF
  
* Dilarang hanya copy paste kode tanpa memahami 

---

## **STUDI KASUS**

Buat program:
**“Sistem Manajemen Layanan Sederhana”**

Fitur utama:

* Data pengguna
* Antrian layanan
* Riwayat aktivitas
* Pencarian data

---

## **TUGAS 1 – ARRAY**

Implementasikan:

* Menyimpan minimal 5 data pengguna dalam array
* Tambah data di posisi tertentu
* Hapus data di posisi tertentu

**Analisis (singkat):**

* Apa kesulitan saat insert/delete?
* Bagian mana paling tidak efisien?

---

## **TUGAS 2 – STACK**

Gunakan stack untuk:

* Fitur “Undo aktivitas”

Implementasi:

* Push (tambah aktivitas)
* Pop (undo)

**Wajib tampilkan output:**

* Sebelum dan sesudah undo

**Analisis:**

* Kenapa stack cocok untuk kasus ini?

---

## **TUGAS 3 – QUEUE**

Gunakan queue untuk:

* Antrian layanan pengguna

Implementasi:

* Enqueue (tambah antrian)
* Dequeue (layani pengguna)

**Wajib tampilkan:**

* Urutan antrian sebelum dan sesudah diproses

**Analisis:**

* Apa yang terjadi jika queue diganti stack?

---

## **TUGAS 4 – LINKED LIST**

Implementasi:

* Buat linked list untuk data pengguna
* Tambah node
* Hapus node
* Tampilkan seluruh data

**Analisis:**

* Bandingkan dengan array (berdasarkan pengalaman coding)
* Mana lebih fleksibel?

---

## **TUGAS 5 – HASH TABLE**

Implementasi:

* Simpan data pengguna (ID → Nama)
* Buat fungsi pencarian berdasarkan ID

**Wajib:**

* Tunjukkan minimal 1 collision (bisa dibuat manual)

**Analisis:**

* Apa dampak collision?
* Bagaimana cara mengatasinya?

---

## **TUGAS 6 – REFLEKSI PRAKTIK (WAJIB)**

Jawab singkat:

1. Struktur data mana paling sulit diimplementasikan?
2. Kesalahan apa yang kamu alami saat coding?
3. Jika sistem diperbesar, bagian mana paling bermasalah?
